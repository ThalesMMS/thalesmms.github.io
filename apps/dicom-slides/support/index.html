dicom-slides support

Setup, troubleshooting, and a direct contact for help.

Install in PowerPoint

Download the manifest from the repository and use Upload My Add-in in a supported PowerPoint client. Organization policy may block custom add-ins; the repository includes desktop installation instructions.

Import a study

Choose Files, Folder or ZIP in the add-in settings. Supported formats vary by importer; the browser importer includes JPEG 2000 and JPEG-LS decoders.

Run the browser version

Open index.html locally. If local script restrictions prevent loading, use the included Python server.

Display and sharing limits

3D requires WebGL2 and sufficient memory. Check a saved presentation in the recipient’s supported PowerPoint client before presenting. This viewer is for demonstration, education and research, not diagnosis.

Project documentation

Find installation details and release-specific guidance in the public project documentation.
