AutoComp / Privacy

Privacy policy

Effective September 5, 2026

This policy describes AutoComp for Safari and the endpoint you choose to connect to it.

What AutoComp processes

AutoComp reads text context before your cursor in Google Docs to request inline suggestions. The current context window is bounded to 2,500 characters and 150 words. It sends that context, completion instructions, and your selected model to your configured OpenAI-compatible HTTPS endpoint.

The configured API key accompanies requests to that endpoint for authentication. The connection test also contacts the endpoint to request its model list. Like any network service you contact, the endpoint can receive your IP address and request metadata.

Settings stored on your Mac

The API base URL, model, API key, and appearance preferences are stored locally in the extension's IndexedDB storage. AutoComp does not sync these settings through iCloud. Its content scripts do not receive the saved API key, and the containing Mac app does not receive it.

This storage is not Apple's Keychain and AutoComp adds no encryption of its own to it. It should not be treated as a vault against access to your local browser profile.

Your chosen endpoint

AutoComp does not route suggestions through a developer-hosted server. Text context and authentication requests go to the endpoint you configure. The endpoint provider's own policies govern its logging, retention, use for model training, and deletion practices. The AutoComp developer does not control those practices.

Review the provider's terms before using it with sensitive documents. Only send information you are authorized to share with that provider.

Developer services and support

AutoComp has no developer-hosted account service or analytics service. It does not send document content or API keys to the developer as part of generating suggestions.

If you email support, the developer receives your email address and the information you choose to include so they can respond. Do not send API keys or sensitive document content.

Your choices

You can change the endpoint and credentials in AutoComp's options. Disable the extension or revoke its site permissions in Safari to stop it operating on documents. Use Safari's extension and data-management controls to remove the extension or its stored data. Revoke an API key with its provider if you need to invalidate it.

Removing local data does not delete requests already received by your endpoint. Contact that provider about its retained data.

This website

This static site has no analytics scripts, forms, or third-party tracking scripts. It is hosted on GitHub Pages; the hosting provider handles web requests under its own privacy practices.

Questions and changes

This policy may be updated when AutoComp's behavior changes. The effective date above identifies this version.
