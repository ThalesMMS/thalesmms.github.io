AutoComp for Safari

Complete and review Google Docs text with local phrase suggestions, optional on-device models or configured AI services.

The Safari extension combines autocomplete with a document assistant, review tools and optional dictation. Available engines and integrations depend on the installed build; other AutoComp applications have different editors, permissions and storage.

Description reviewed November 2, 2026

Setup & support Read the privacy policy

Suggestions and abbreviations

Use a local TXT phrase library and editable abbreviations before requesting AI completions.

Choose a model

Use an installed browser model when the build and device support it, or configure an AI endpoint. Model installation and activation are separate choices.

Review and edit

Review text in five categories, ask questions and inspect proposed document edits before applying them.

Dictation and search

Configure speech recognition and optional semantic search independently from the text-generation provider.

Other AutoComp implementations

Native macOS uses Accessibility to work in supported text fields. Native iPhone/iPad and Android apps use their own editors. A separate Flutter workbench targets Windows, macOS, iOS and Android; its web target is unsupported.

Chrome and OnlyOffice implementations also exist. Their host integration and feature availability differ from Safari. These are separate implementations, not a promise of store availability, feature parity or shared privacy settings.
