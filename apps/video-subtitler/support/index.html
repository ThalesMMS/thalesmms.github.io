Video Subtitler / Support

Video Subtitler support

Setup, troubleshooting, and a direct contact for help.

Create a project

Import a local video and wait for the import to finish before transcription. If the app reports missing media, use its relink workflow to select the source again.

Prepare local models

Choose a speech-recognition model and language provider in Settings. The first use can require a large download and enough free storage for models and working files.

Local Qwen and OmniVoice require compatible physical-device hardware. Apple Intelligence options also depend on system availability. A model cache can be removed and downloaded again without serving as a backup of your projects.

Configure a remote provider

Enter the endpoint, model and optional API key in Settings. Use HTTPS; local HTTP requires explicit consent for the connection and separate permission to send credentials.

Remote embeddings are configured independently from the generation provider. Check both choices if a search or language operation fails.

Review and export

Review timing, translations and generated speech before exporting. Choose SRT for a subtitle file or a video export option for the desired playback behavior.

Keep enough free storage for the source media, working files and export. Use export history to manage artifacts, and keep external copies of work you want to preserve.

Remove a project

Delete project removes its local project files, including associated transcript, chat, indexes and exports kept inside that project. It does not recall copies already shared elsewhere or clear the separately stored API credential.

Contact support

Contact Thales Matheus M Santos about Video Subtitler at thalesmmsradio@gmail.com.

Include the app or package version, your operating system, the steps to reproduce the problem, and a sanitized error message. Do not send patient information, private documents or source code, API keys, passwords, or private keys.
