Video Subtitler privacy policy

Effective September 5, 2026

How Video Subtitler handles data, including the services and integrations you choose to use.

Local project storage

The app stores imported media, project metadata, subtitles, translations, chat, indexes, recovery copies and generated exports on the device. Temporary working files may exist during import, transcription and export.

Non-secret preferences are kept separately from projects. Deleting a project does not reset preferences or remove model downloads.

Local processing and downloads

The default generation provider is Local Qwen and the default retrieval method is local TF-IDF. Whisper transcription, supported local language models, dubbing and export process content on the device when the required assets and hardware are available.

Whisper, Qwen and OmniVoice assets can be downloaded from model hosting services such as Hugging Face. Apple-managed models or voices may require system downloads. These preparation requests contact external services even when your media processing is local.

Optional remote text operations

Selecting a remote generation provider sends operation-specific text directly to the chosen endpoint. Translation can include subtitle cues, target language and instructions; chat can include the question, recent completed turns and selected transcript excerpts; summaries can include transcript groups and intermediate summaries.

Remote embeddings are a separate option that sends searchable transcript text during index creation and query text during retrieval. These text operations do not upload the raw source video or audio.

Credentials and connections

The optional remote API key is stored in Apple Keychain separately from the project. HTTPS requests can include it as a bearer credential. Public HTTP endpoints are blocked, and local HTTP requires separate data and credential permissions.

The remote HTTP client uses an ephemeral session without its own URL cache or cookie store. This does not control logging or retention at the destination.

Deletion, caches and backup

Delete project removes that project’s local directory. Model caches, preferences and Keychain credentials have separate lifecycles. A Keychain item may survive app removal, and saving an empty API key does not prove the Keychain record itself was deleted.

The operating system controls device backup and restoration. A model cache is not a project backup, and deleting local data does not remove exports, backups or copies held by a remote endpoint.

Diagnostics and external services

The audited app does not configure advertising, third-party analytics or a developer-operated project-upload backend. Local job and error diagnostics support troubleshooting.

A chosen AI endpoint and model-download service can receive connection information and the requests you send to it. Their operators control their own logging, retention and deletion; no uniform retention period is promised here.

This support website

This static website does not use analytics scripts, forms, or third-party tracking scripts. GitHub Pages handles requests to the website under its own hosting and privacy practices. Visiting a source repository or contacting another service is subject to that service's policies.
