TotalSegmentator OsiriX/Horos Plugin support

Setup, troubleshooting, and a direct contact for help.

Prepare the host

Install the plugin for a supported OsiriX or Horos environment and follow the repository’s build and installation instructions. Host compatibility and ROI behavior require validation in the actual viewer.

Check dependencies

Use environment checks to verify Python, TotalSegmentator and dcm2niix. Managed setup installs pinned Python dependencies and may download a conversion binary.

Managed setup in the linked project pins TotalSegmentator 2.18.0 and checks hash-locked Python dependencies. An independently selected installed environment can have another version.

Run a segmentation

Select an appropriate series, choose a supported task and output directory, and review device and license requirements. Model weights may need downloading before the first run.

Review results and failures

Inspect the progress log and output/provenance records when a run fails. Verify imported segmentation alignment and completeness against the source images; successful processing is not clinical validation.

Review usage reporting

For the inspected Python library, usage reporting is controlled by send_usage_stats in config.json, normally in the .totalsegmentator directory under the user home. Set it to false to disable usage-report requests, and verify the directory and behavior for the runtime selected by the plugin. No native telemetry toggle was identified.

Separate plugin implementations

The linked Swift OsiriX/Horos plugin currently pins TotalSegmentator 2.18.0 for managed setup. A separate reconstructed native plugin has an IsiX compatibility build; it is not the same implementation and has separate host and runtime limits.

IsiX also has native on-device segmentation in supported Apple application builds. That workflow does not use this Python plugin. Stable macOS plugin interfaces and the 6.0 IsiXPluginKit beta interface must be checked separately.
