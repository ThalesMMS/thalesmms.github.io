TotalSegmentator OsiriX/Horos Plugin privacy policy

Effective September 5, 2026

How TotalSegmentator OsiriX/Horos Plugin handles data, including the services and integrations you choose to use.

Local series processing

The plugin exports source image data for a local Python segmentation process and imports supported outputs into the host viewer. Source data, derived masks and run artifacts can contain sensitive information.

Dependencies and models

Environment preparation uses package downloads and may retrieve dcm2niix from GitHub. TotalSegmentator downloads missing model weights; some tasks require a license and contact its backend.

TotalSegmentator telemetry

The bundled Python library creates configuration with send_usage_stats enabled by default. Its usage request contains an installation identifier, run counter, task/options, platform and Python/GPU information, and a license number when present. The inspected request does not include image pixels or patient tags and uses an HTTP backend endpoint.

In the inspected library, setting send_usage_stats to false in its config.json disables these usage-report requests. Check the configuration directory used by your installed runtime; this setting does not disable model downloads or license-related requests.

Installed runtime matters

The plugin can use an installed Python environment or prepare one with pinned packages. Network and telemetry behavior must be checked in that actual TotalSegmentator version and its configuration; the native plugin does not establish a blanket offline or no-collection guarantee.

Stored settings and outputs

Plugin preferences, including an optional license key, are stored in macOS user defaults in the inspected code. Output directories retain segmentation and provenance artifacts, and progress logs can contain local paths. The host viewer manages its own database and ROI persistence.

Cleanup and deletion

The plugin includes temporary-export cleanup and staging cleanup, but completed outputs and host records have separate lifecycles. Review remaining output directories, logs, backups and viewer records when removing a case; no universal automatic deletion period is specified.

This support website

This static website does not use analytics scripts, forms, or third-party tracking scripts. GitHub Pages handles requests to the website under its own hosting and privacy practices. Visiting a source repository or contacting another service is subject to that service's policies.
