Podcast Intelligence / Privacy

Podcast Intelligence privacy policy

Effective September 5, 2026

How Podcast Intelligence handles data, including the services and integrations you choose to use.

Media and derived data

Desktop processing stores imported media, playback files, transcripts, summaries, vectors and conversations in application data. Server deployments store these using their configured infrastructure.

Remote imports

Podcast resolution and media downloads contact directory, feed, transcript and media hosts. Those hosts receive the network requests needed for the import.

AI providers

Configured transcription services can receive audio. Embedding and language-model services receive relevant transcript text, questions and context. Endpoints can be local or remote; local desktop packaging does not make remote AI processing local.

Credentials

Desktop provider settings, including supplied credentials, are saved in a local settings file with platform permission handling. They are not described as encrypted storage. Codex CLI mode uses the CLI authentication configured on the machine.

Connected clients

Optional MCP access exposes supported episode tools to connected clients. Content returned to a client is then subject to that client and any AI services it uses.

Exports and removal

Exported transcripts and summaries remain in the selected destination. To remove the desktop library, quit the application and remove its application data after preserving anything needed; exported copies and remotely processed data require separate handling.

Diagnostics

The inspected application has operational logs but no integrated analytics or crash-reporting service was found. Review logs and exported content before sharing them for support.

This support website

This static website does not use analytics scripts, forms, or third-party tracking scripts. GitHub Pages handles requests to the website under its own hosting and privacy practices. Visiting a source repository or contacting another service is subject to that service's policies.

Privacy questions and support

Policy updates

This policy may change when the software's data handling changes. The effective date above identifies this version. Features and integrations can differ by release and platform.
