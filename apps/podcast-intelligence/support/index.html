Podcast Intelligence support

Setup, troubleshooting, and a direct contact for help.

Set up processing

Choose providers in desktop settings. The default demo profile supplies demonstration behavior; configure suitable transcription, embedding and language-model providers for real processing.

Import problems

Confirm that a URL resolves to accessible public media or RSS. Protected, unsupported, oversized or unsafe download destinations may be rejected.

Provider problems

Check the endpoint, API key, model and supported audio or embedding options. Save settings and restart the engine when requested.

Transcripts and exports

Review speaker labels and source timestamps before relying on generated text. Select an export format and save location.

Desktop and server storage

Desktop mode uses local SQLite and file storage. A separately deployed server uses its configured database and object store, so storage and access depend on that deployment.

Project documentation

Find installation details and release-specific guidance in the public project documentation.
