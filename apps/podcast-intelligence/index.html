Podcast Intelligence

Turn podcast episodes and media files into transcripts, summaries and searchable answers.

Import local media or resolve podcast links, then explore timestamped transcripts and summaries. Ask questions with citations that return you to the source audio.

Setup & support Read the privacy policy

Flexible import

Import audio/video files, media URLs and podcasts through RSS or supported directory links.

Timestamped understanding

Reuse published transcripts or configure transcription, summaries and speaker-aware processing.

Grounded questions

Search episode content and follow answer citations to playback positions.

Export and integration

Export JSON, Markdown, SRT or VTT and optionally connect compatible clients through MCP.

Desktop and server deployments

The macOS and Windows desktop packages and server deployment share processing components but have different storage and service configuration. Public and development checkouts are separate snapshots; a local desktop backend can still use remote AI providers.
