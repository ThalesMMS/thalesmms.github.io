Logisim Evolution Mobile

Design and simulate digital logic circuits on phones and tablets.

This independent open-source port of Logisim Evolution provides a mobile circuit editor and simulator. Start with a bundled example or open a supported .circ project.

Setup & support Read the privacy policy

Circuit editor

Place and wire components, edit properties, and organize related circuits in a project.

Logic simulation

Inspect signals and step through supported digital logic circuits.

Examples and file exchange

Open built-in examples such as SAP-1 and import or export supported .circ projects.

Optional desktop tools

Pair with a companion host of your choice when you need supported external tools.
