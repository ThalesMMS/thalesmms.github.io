DICOM tools for AI agents support

Setup, troubleshooting, and a direct contact for help.

Choose the component

Use dicom-skill for shell workflows, dicom-plugin for its integrated tools, or dicom-viewer-mcp-app for the standalone viewer. The separate MCP viewer requires Node.js, a build, and a compatible MCP host; follow its public repository instructions. Component capabilities differ.

Configure a PACS

Supply authorized endpoint, AE title and port information. In the integrated plugin, DICOM_MCP_CONFIG selects the shared node configuration. Verify connectivity before retrieving or sending data.

Open images

The separate viewer reads a local dicom folder and supports uncompressed images. The integrated plugin additionally supports preparation workflows and local HTML output for hosts without inline MCP Apps.

Troubleshoot transfers

Check endpoint reachability, AE permissions, transfer syntax and destination receiver configuration. Temporary Orthanc workflows require Docker and create local storage.

Review outputs

Check anonymized files and rendered previews before sending or sharing. These tools do not establish diagnostic suitability or certify de-identification.
