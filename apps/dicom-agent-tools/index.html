DICOM tools for AI agents

DICOM query, transfer, conversion and viewing tools for agent-assisted workflows.

The set brings together dicom-plugin, dicom-skill, and dicom-viewer-mcp-app. Connect authorized PACS workflows with local processing and interactive or file-based previews in compatible agent hosts.

Setup & support Read the privacy policy

Query and transfer

Use configured DICOM nodes to verify connections, query studies and retrieve or send instances.

Local processing

Anonymize metadata, transcode JPEG 2000, encapsulate PDFs and export PNG or MP4 previews.

Host-aware viewing

The integrated viewer supports MCP Apps and a local HTML fallback; the separate viewer repository provides a simpler prototype.

Configurable destinations

Configure PACS endpoints and supported authentication or transport options for your deployment.
