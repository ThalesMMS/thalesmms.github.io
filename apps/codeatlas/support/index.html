CodeAtlas support

Setup, troubleshooting, and a direct contact for help.

Choose a workspace

Open Settings, select the repository folder and apply it. Follow the restart prompt when changing the active workspace.

Configure explanations

Set an OpenAI-compatible endpoint and model in Settings. Builds with the Codex option can instead use an installed Codex CLI signed in with ChatGPT. Check the provider readiness result before generating explanations; a local CLI process still uses remote model inference.

Semantic tools

Optional language servers improve semantic evidence. Missing servers reduce precision but do not replace the local parser index.

Review generated output

Follow citations to source and check inferred behavior before relying on explanations or proposed changes.

Build differences

Desktop and browser/server modes share the repository index. Newer development builds also offer Codex CLI with ChatGPT authentication as an alternative generation provider. Older builds can offer only the OpenAI-compatible provider; check Settings in your installed version.

Contact support

Contact Thales Matheus M Santos about CodeAtlas at thalesmmsradio@gmail.com.

Include the app or package version, your operating system, the steps to reproduce the problem, and a sanitized error message. Do not send patient information, private documents or source code, API keys, passwords, or private keys.
