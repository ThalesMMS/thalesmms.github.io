CodeAtlas / Privacy

CodeAtlas privacy policy

Effective September 5, 2026

How CodeAtlas handles data, including the services and integrations you choose to use.

Local repository data

CodeAtlas reads the selected workspace and stores a derived SQLite index, normally in a .codeatlas directory within that workspace. Saved editor changes modify the selected source files.

AI requests

Generated explanations and documentation send prompts and relevant source evidence to the configured chat endpoint. A remote provider receives that content; provider connection tests also make requests.

Settings and credentials

Settings are stored for the current operating-system user. Credentials entered through Settings use the system credential vault; credentials supplied through environment files remain governed by how those files are stored.

Local interface

The default server listens on the loopback interface and the desktop app uses an embedded web view. Changing the listen address changes who may be able to reach the service.

Removal and diagnostics

Quit the app before removing a derived index or local settings. Remove saved credentials through the configured credential controls and manage source files and exports separately. No integrated analytics or crash-reporting service was found in the inspected source.

This support website

This static website does not use analytics scripts, forms, or third-party tracking scripts. GitHub Pages handles requests to the website under its own hosting and privacy practices. Visiting a source repository or contacting another service is subject to that service's policies.

Privacy questions and support

Contact Thales Matheus M Santos about CodeAtlas at thalesmmsradio@gmail.com.

If you email us, we receive your email address and the information you choose to send to respond to your request. Please omit patient information, private documents, and credentials.

Policy updates

This policy may change when the software's data handling changes. The effective date above identifies this version. Features and integrations can differ by release and platform.
