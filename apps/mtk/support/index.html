MTK — Metal Toolkit support

Setup, troubleshooting, and a direct contact for help.

Integrate the rendering core

Add the public MTK repository with Swift Package Manager and select MTKCore. MTKFixtures is available for synthetic test volumes. The audited package declares Swift tools 6.0 and iOS, macOS, and visionOS 26.0 minimums.

MTK does not include a ready-made viewer or DICOM parser. Supply a decoded volume with valid dimensions, spacing, orientation, and pixel type. See the public repository for integration documentation.

Check Metal support

Use a device and runtime with the required Metal capabilities. If availability checks fail, inspect the reported capability before attempting rendering. Keep the device and OS information in a support report.

A volume looks wrong

Check signed versus unsigned pixels, dimensions, voxel spacing, orientation, rescale handling, and the selected transfer function. Reproduce with a synthetic fixture to separate data-loading problems from rendering.

Inspect rendering or export failures

Include the MTK version, device, OS, pixel format, and a minimal reproduction using synthetic data. Review local rendering logs before sharing them. Snapshot export writes to a destination chosen by your application and requires a supported texture format.

Core package and integration builds

The public package exposes the rendering core and fixtures. Development and application-embedded copies can also include MTKUI and additional interaction tools; their products are not identical.

The inspected public package uses Swift tools 6.0 and declares iOS, visionOS and macOS 26.0 minimums. Host applications and Metal features can impose additional requirements.
