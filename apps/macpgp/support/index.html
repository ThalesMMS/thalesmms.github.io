MacPGP support

Setup, troubleshooting, and a direct contact for help.

Check compatibility

Use an Apple Silicon Mac running macOS 26.2 or later. Intel Macs are not supported by the current bridge.

Encryption and decryption

Import the intended recipient public key and verify its fingerprint. Decryption requires the matching private key and any required passphrase.

Enable extensions

Enable the relevant Finder, Quick Look, thumbnail or sharing extension in macOS settings. Relaunch Finder if changes are not reflected.

Keyserver failures

Check the selected server and network connection. Insecure search or retrieval requires explicit opt-in; uploads require secure transport.

Key deletion warnings

If deletion reports cleanup failures, retry the indicated cleanup. Keep any required private-key backup before deleting a key.

Project documentation

Find installation details and release-specific guidance in the public project documentation.
