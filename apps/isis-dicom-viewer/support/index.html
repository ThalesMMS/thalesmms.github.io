IsiX DICOM Viewer support

Setup, troubleshooting, and a direct contact for help.

Start with an import

Choose a DICOM file or supported archive through the app’s import flow. Check the activity result if a study is incomplete or cannot be decoded.

Connect an archive

Confirm the host, port, AE titles or DICOMweb base address with the archive administrator. Check authentication and TLS settings, then test the connection before retrieving studies.

Receiving studies also requires the listener configuration and network access. On Android, the clear-text listener waits for acknowledgement of its access warning. Configure scheduled query/retrieve rules only for archives you intend the app to contact automatically.

Check the viewing mode

MPR and 3D depend on suitable image geometry, the included rendering backend and device resources. A missing mode or failed reconstruction does not establish that the source study is invalid.

These tools do not establish clinical certification or automatic diagnostic correctness. Review measurements and exported results for your intended use.

Manage storage and sharing

Deleting a local study and clearing derived data serve different purposes. Cache cleanup does not remove an archive’s original study.

Review patient information, image annotations and burned-in text before exporting or sharing. A hidden overlay is not proof that a DICOM file or image is anonymized.

Contact support

Contact Thales Matheus M Santos about IsiX DICOM Viewer at thalesmmsradio@gmail.com.

Include the app or package version, your operating system, the steps to reproduce the problem, and a sanitized error message. Do not send patient information, private documents or source code, API keys, passwords, or private keys.
