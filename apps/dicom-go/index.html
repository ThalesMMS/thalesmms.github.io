dicom-go

Read, write, inspect, and exchange DICOM datasets with Go.

dicom-go combines reusable DICOM packages with command-line tools for file inspection and network workflows. Build applications that process metadata and pixels, convert DICOM JSON, or exchange studies with configured services.

Setup & support Read the privacy policy

Work with files and pixels

Read and write DICOM datasets, extract pixel data, and convert between datasets and DICOM JSON.

Connect imaging systems

Use the supported DIMSE, DICOMweb, and JPIP interfaces in a host-controlled networking workflow.

Build focused tools

Combine command-line inspection, storage, rendering, and de-identification helpers. Codec and rendering support depends on the chosen modules and data format.
