Add a repository

Choose a local Git working tree with Add repository, then select an analysis profile and date range.

Configure AI

Set the chat and embedding endpoints, models and credentials in Settings. Test connections and verify embedding dimensions when indexing fails.

Hosted project activity

Enable PRs & issues to fetch supported GitHub or GitLab activity. Configure a token when required by repository access or rate limits.

Review stories

Use citations to check the underlying commits and evidence. A factual fallback story can be produced when an AI request fails.

Browser preview

The browser preview uses demonstration data. Real Git analysis, persistence and AI requests require the desktop application.
