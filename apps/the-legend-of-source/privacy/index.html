The Legend of Source - Branches of Time privacy policy

Effective November 2, 2026

How The Legend of Source - Branches of Time handles data, including the services and integrations you choose to use.

Repository access

Analysis reads Git history and optional text patches or blobs according to the selected profile. Derived application data is written to the per-user application-data directory rather than the analyzed repository.

Local records

The application stores repository identities and paths, commit metadata, indexed text, embeddings, stories and conversations in SQLite. Author identities and source content can be part of that data.

AI endpoints

Story generation, release-note summaries and chat send selected repository evidence and questions to the chosen provider. The OpenAI-compatible mode uses the configured chat endpoint. The optional Codex mode runs a local Codex app-server process that sends requests through the signed-in ChatGPT account; model inference is remote.

Indexing sends document text to the separately configured embedding service. Default compatible endpoints are loopback addresses, but settings and environment values can select remote services.

Hosting integrations

When enabled, hosted activity retrieval contacts GitHub or GitLab. A configured token is used where available; GitHub can fall back to the locally authenticated gh CLI or anonymous public access.

Credentials

Saved compatible-provider settings, including AI credentials and hosting tokens, are serialized into the local SQLite database. This is not an encrypted credential vault; protect application data and its backups.

The Codex option stores provider preferences separately and delegates credentials to an isolated Codex authentication directory within application data. Its sign-out flow does not delete the normal shared Codex CLI login.

Removal and export

Removing a repository from the library removes its derived database records without deleting the Git working tree. Exported Markdown, application backups and data already sent to external services require separate handling.

Diagnostics

The inspected source does not integrate an analytics or crash-reporting service. Connection errors and local diagnostics can still contain operational details, so review support material before sharing it.

This support website

This static website does not use analytics scripts, forms, or third-party tracking scripts. GitHub Pages handles requests to the website under its own hosting and privacy practices. Visiting a source repository or contacting another service is subject to that service's policies.
