IsiX DICOM Viewer for macOS

View and organize DICOM studies locally, with MPR, 3D reconstruction and connections to configured PACS servers.

This independently maintained, Horos-derived macOS application has separate GitHub and sandboxed Mac App Store builds. The current build configuration targets macOS 15 or later, with separate Apple Silicon and Intel packages. These privacy and data collection pages apply specifically to the Mac App Store edition. Not for diagnostic use.

Description reviewed November 2, 2026

Setup & support Read the privacy policy

Local study management

Import files and folders, inspect DICOM metadata, organize studies and export selected images or DICOM objects.

Image viewing

Adjust window level and width, create measurements and use MPR, curved MPR and 3D reconstruction with suitable image series.

PACS connections

Query, retrieve and send studies using compatible DICOM and DICOMweb services configured by the user.

Mac App Store edition

App Sandbox controls access to selected folders. Updates use the App Store, and external plugins are disabled.

Distribution and plugin compatibility

The stable 5.3.x GitHub line keeps its existing plugin interfaces. The 6.0 beta line uses IsiXPluginKit and needs plugins built for that interface. Check the installed version before choosing a plugin.

Mac App Store builds use App Sandbox, App Store updates and no external plugins. GitHub builds have different permissions, external plugin support and a GitHub updater. Separate Intel packaging does not establish testing on Intel hardware.
