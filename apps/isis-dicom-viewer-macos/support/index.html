IsiX DICOM Viewer for macOS support

Setup, troubleshooting, and a direct contact for help.

Choose the correct Mac build

Use the package for your Mac architecture and check its release requirements. The inspected configuration declares macOS 15 as its minimum; an installed older release or beta can differ.

Stable GitHub builds, beta builds and Mac App Store builds have different update and plugin behavior. The privacy and data collection declarations on this site remain scoped to the Mac App Store edition.

Import and view a study

Use Import in the database toolbar to choose a DICOM file or folder, then open a series from the database. No developer account is required to view local files.

MPR and 3D reconstruction require suitable image geometry. These tools are not for diagnostic use.

Connect to a PACS

Obtain the host, port, AE titles or DICOMweb address from your archive administrator. Configure authentication and secure transport as required by that server.

Receiving and sharing services and automatic transfer rules can communicate with other systems after you enable them. Check their destination and access settings before use.

Folders and distribution editions

The Mac App Store edition stores its default database in application storage. Use the macOS file picker to grant access to an external database or import and export folders.

Updates are delivered through the App Store. External plugins and the GitHub updater are disabled in this edition. The GitHub distribution has different permissions and extension options.

Report a problem

Provide the app version, macOS version and steps to reproduce the problem. Use anonymized examples and review screenshots or logs for patient identifiers before sharing them.

Distribution and plugin compatibility

The stable 5.3.x GitHub line keeps its existing plugin interfaces. The 6.0 beta line uses IsiXPluginKit and needs plugins built for that interface. Check the installed version before choosing a plugin.

Mac App Store builds use App Sandbox, App Store updates and no external plugins. GitHub builds have different permissions, external plugin support and a GitHub updater. Separate Intel packaging does not establish testing on Intel hardware.
