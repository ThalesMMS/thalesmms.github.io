DICOM-Swift support

Setup, troubleshooting, and a direct contact for help.

Add the package

Add the public DICOM-Swift repository as a Swift Package dependency and select DicomCore. The audited package requires Swift 6.2 and declares iOS, macOS, and visionOS 26.0 minimums; check the manifest for the release you use.

The package is a library and CLI, not a standalone viewer. Start with the repository getting-started guide and synthetic or de-identified test files.

Inspect and export

Build the dicomtool product and open its help to select the inspection or export command. Confirm the input path, output directory, and transfer syntax before processing a large series.

A file does not decode

Report the transfer syntax UID, pixel format, selected codec, package version, and the error. Codec support varies by syntax and platform; some paths delegate to optional native backends. Metadata may remain readable when pixel decoding is unavailable.

A network request fails

Verify the configured server URL or AE title, host, port, authentication, transport security, and supported operation. The calling application must supply the appropriate connection and authorization policy. Remove patient identifiers, server response bodies, and credentials before sharing diagnostics.
