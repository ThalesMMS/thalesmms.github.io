DICOM-Swift

Decode DICOM files and build imaging, DICOM networking and supported HL7/FHIR workflows in Swift.

DICOM-Swift supplies DICOM libraries, SwiftUI integration and command-line tools. Optional products add HL7 v2, CDA, FHIR R4 and clinical mappings; each product has its own supported scope.

Description reviewed November 2, 2026

Setup & support Read the privacy policy

Read and decode

Inspect metadata, decode supported pixel formats, and assemble series from files, folders, or ZIP archives.

Prepare and export

Apply window and level settings and export images, with explicit choices for annotations and metadata.

Integrate DICOM services

Use DICOMweb and DIMSE helpers for supported query, retrieval, storage, and related workflows. The host application owns the user interface and connection policy.

Clinical messages and documents

Optional packages parse and transform supported HL7 v2, CDA and FHIR content. Their validators cover documented subsets and do not certify complete standard conformance.

Standalone and embedded packages

The public package and copies embedded in applications can be at different revisions. Check the package manifest and release notes for the exact version selected by your app. A host application can impose a higher OS minimum than the library.
